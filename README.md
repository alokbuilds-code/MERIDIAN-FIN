## ⚡ CORE CAPABILITIES

* **Cinematic Boot Sequence**: Finite State Machine (`INTRO_INIT` → `INTRO_REVEAL` → `INTRO_HOLD` → `INTRO_EXIT` → `INTRO_FRAGMENT` → `INTRO_COMPLETE`) driving razor-sharp typography into high-velocity particle disintegration.
* **Procedural Acoustic Synthesis**: Zero MP3/WAV assets. Synthesizes sub-bass sweeps (55Hz–110Hz), resonant noise whooshes, and cinematic impact transients mathematically via native Web Audio `BiquadFilter` and `OscillatorNode`.
* **Interactive 3D Brushed Metal Card**: Real-time perspective matrix tilt and dynamic specular light dispersion calculated relative to cursor coordinates.
* **Live Settlement Streamer (LSE-1)**: High-frequency simulated gross settlement pipeline generating multi-currency enterprise ledger transitions every 2.4s.
* **Global Treasury FX Engine**: Interbank foreign exchange calculator with zero-slippage spread models across USD, EUR, GBP, JPY, SGD, and CHF.
* **Failsafe Architecture**: Logo and typography render visible by default in pure CSS. Complete resilience against script blocks or execution interruptions.

## 🚀 QUICK START

No bundlers. No package managers. No build pipeline required.

### 1. Direct Execution
Open `index.html` directly in any modern browser:
```powershell
Start-Process "index.html"
```

### 2. Local HTTP Server (Optional)
```powershell
python -m http.server 8080
# or
npx serve .
```
Navigate to: `http://localhost:8080`
